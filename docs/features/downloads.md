# ダウンロードマネージャー

作品の画像保存およびオフライン保存用キュー管理機能の仕様です。

---

## 保存オプション (`AppSettings`)

- **原寸画像保存**: メタデータからオリジナルの画像 URL を取得して保存。
- **マルチページ一括保存**: マンガ等の全ページをフォルダにまとめてダウンロード。
- **フォルダ自動振り分け**:
  - `downloadFolderByArtist`: 作者名（ユーザーID）ごとにフォルダを作成して分類。
  - `downloadFolderByWork`: 作品ID（タイトル）ごとにサブフォルダを作成。

---

## キュー管理 (`DownloadQueueScreen`)

- **並列タスク数制御 (`simultaneousDownloads`)**: 同時ダウンロード数を 1〜5 の範囲で設定可能。
- **状態管理**: キュー内の各タスク（待機中、ダウンロード中、完了、エラー、一時停止）の進行状況とプログレス表示。
- **ネットワーク制御 (`offlineWifiOnly`)**: Wi-Fi 接続時のみダウンロードを実行する制限設定。

---

## オフラインライブラリ (`OfflineLibraryScreen`)

保存された作品データは Room データベースで管理されます。

- **テーブル構造**:
  - `SavedIllustEntity`: 保存済み作品の基本情報（ID、タイトル、作者、保存日時）
  - `SavedIllustPageEntity`: 各ページのローカルファイルパスおよび画像インデックス
- ネットワーク非接続時でも、保存済み作品をライブラリからオフライン閲覧可能です。
