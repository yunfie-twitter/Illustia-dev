# ブックマーク & フォロー管理

気になった作品の保存および好みの作者の追跡を行う管理機能の仕様です。

---

## ブックマーク機能 (`BookmarkScreen`)

作品詳細画面および各種一覧のブックマークアイコンから操作可能です。

### 1. 公開範囲 (`Restrict`)
- `Restrict.Public`: プロフィール上に公開されるブックマーク。
- `Restrict.Private`: 自分のみが参照可能な非公開ブックマーク。

::: tip クイック切替ショートカット
ブックマークボタンを長押しすることで、公開範囲および付与するブックマークタグを直接指定できる設定ダイアログが起動します。
:::

### 2. ブックマーク用タグ
Pixiv のブックマーク分類タグに対応しています。
- ブックマーク追加時、作品に登録されているメインタグから選択またはカスタムタグを手動入力。
- ブックマーク一覧画面において、設定されたタグでフィルタリング閲覧が可能。

---

## フォロー管理 (`UserProfileScreen`)

- **公開フォロー (`Restrict.Public`)**: 作者にフォローが通知され、自身のフォロー中一覧に公開表示。
- **非公開フォロー (`Restrict.Private`)**: 作者に通知されず、非公開で更新を追跡。
- **フォロー中タイムライン**: ホーム画面の「フォロー中」タブから、フォローしている全クリエイターの新着投稿をタイムライン形式で一括閲覧。

---

## 自動アクション連動フラグ (`AppSettings`)

設定画面で有効化できる連携機能のフラグ一覧です。

| フラグ名 | 型 | 説明 |
| :--- | :--- | :--- |
| `autoDownloadOnBookmark` | `Boolean` | 作品をブックマークに追加した際、同時にバックグラウンドでローカルストレージへ保存 |
| `autoBookmarkOnDownload` | `Boolean` | 作品をローカルへダウンロード保存した際、同時に Pixiv 上のブックマークにも追加 |
| `autoTagOnBookmark` | `Boolean` | ブックマーク追加時、作品のトップタグを自動的にブックマークタグとして設定 |
| `followOnLike` | `Boolean` | 作品を「いいね！」した際、作者を自動的にフォロー |
| `privateBookmarkDefault` | `Boolean` | ブックマーク追加時の初期選択状態を「非公開」に固定 |
