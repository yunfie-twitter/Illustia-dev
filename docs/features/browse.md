# 作品閲覧

イラスト・マンガ・小説・うごイラ（アニメーション）の各メディアに対応した閲覧画面を提供します。

---

## タブおよびフィード構成

- **おすすめ (Home)**: 関連イラストおよび推奨コンテンツの表示。
- **フォロー中**: フォロー中ユーザーの最新作品タイムライン。
- **ランキング (`RankingScreen`)**: デイリー、ウィークリー、マンスリー、R-18、女子人気、男子人気などの各ランキング。
- **ショートフィード (`ShortsFeedScreen`)**: フルスクリーンでの縦スワイプ閲覧。
- **小説 (`NovelScreen`)**: 小説作品一覧および本文リーダー。

---

## コンテンツ別ビューア機能

### 1. イラスト・マンガビューア (`ImageViewerScreen`)

- **高解像度ズーム**: ピンチ操作による拡大・縮小。
- **複数ページ閲覧**: マルチページ作品のスライド切り替えおよび見開き表示。
- **解像度制御**: `AppSettings` の各種品質設定に連動。
  - `feedPreviewQuality`: フィードサムネイル品質 (`low` / `high`)
  - `illustDetailQuality`: イラスト詳細表示画質 (`medium` / `high` / `original`)
  - `fullscreenQuality`: フルスクリーンビューア画質 (`high` / `original`)

### 2. うごイラ再生 (`UgoiraArtwork`)

- Pixiv のうごイラ Zip アーカイブ（JPEG/PNG フレームデータ）をダウンロードし、`UgoiraMetadata` のフレーム遅延情報に基づいてアニメーション生成・再生。
- 一時停止、フレーム送り、繰り返し再生の制御に対応。

### 3. 小説リーダー (`NovelScreen`)

- **レイアウト設定**: 縦書き（和文表示）および横書きの切り替え。
- **読書カスタマイズ**: フォントサイズ、行間、背景テーマ（ホワイト、セピア、ダーク）の選択。
- **挿絵埋め込み**: 文中の `[pixivimage:id]` 形式の挿絵コードを解析し、インライン/ポップアップ表示。

---

## ユーザープロフィール (`UserProfileScreen`)

作者名をタップするとユーザー詳細画面を表示します。
- 投稿イラスト・マンガ・小説のタブ分け表示
- 公開ブックマーク作品
- フォロー / フォロー解除切り替え（公開・非公開の選択）
- ユーザーのミュート登録
