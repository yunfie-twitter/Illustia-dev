# 外観テーマと各種設定

---

## テーマと外観

- **ダークモード / ライトモード**: 目に優しいダークテーマに切り替えられます。
- **AMOLED モード**: 有機EL画面に最適な「真っ黒（純黒）」テーマが使えます。

---

## ミュート機能

見たくない作品や苦手な表現をフィードから隠すことができます。

- **ユーザーミュート**: 指定した絵師さんの作品を非表示にします。
- **タグミュート**: 特定の言葉やタグが入った作品を隠します（例: ネタバレ、苦手なジャンルなど）。

---

## 設定のバックアップと復元

機種変更をするときや、別の端末に設定を引き継ぎたいとき、設定データをファイル（JSON）として保存・読み込みできます。
