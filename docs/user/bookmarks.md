# ブックマークとフォロー

---

## ブックマーク

気に入ったイラストや小説を自分のコレクションに保存できます。

- **公開 / 非公開**: ブックマークするときに「公開」か「非公開（自分だけが見られる）」を選べます。
- **長押しショートカット**: ブックマークボタンを長押しすると、公開範囲やタグを直接選べる画面が開きます。

---

## フォロー

大好きな絵師さんをフォローすると、相手の新しい投稿を逃さずチェックできます。

- **公開フォロー / 非公開フォロー**: こっそり更新を追いたい場合は非公開フォローが使えます。
- **フォロー中タブ**: ホーム画面の「フォロー中」タブを開くだけで、フォローしている方の最新作がまとめて見られます。
