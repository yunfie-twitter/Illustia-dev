# ログインとアカウント設定

Palleria を使用するには Pixiv アカウントでログインが必要です。

---

## ログイン手順

アプリを起動するとログイン選択画面が表示されます。

### 1. Web ログイン (通常はこちら)
1. **「Web ログイン」** をタップします。
2. Pixiv の公式ログイン画面が開くので、メールアドレスとパスワードを入力してログインします（Google / Apple などの連携アカウントも利用できます）。
3. ログインに成功すると、自動的に Palleria の画面に戻り準備が完了します。

### 2. リフレッシュトークンでログイン (上級者向け)
すでに Pixiv の `refresh_token` を所持している場合は、トークン文字を直接入力してログインすることも可能です。

---

## 安全性について

ログイン時に入力したパスワードが Palleria 側に保存されることはありません。ログイン後に発行される認証コードのみが、スマホ内の安全な領域（暗号化ストレージ）に保存されます。

---

## 複数アカウントの切り替え

家族用や用途別に複数のアカウントをお持ちの場合、ログイン状態を保持したまま切り替えることができます。

- アカウント設定画面や、メニューのアカウント切り替えシートからいつでも別のアカウントに切り替えが可能です。
- アカウントごとに個別でログアウトすることもできます。
