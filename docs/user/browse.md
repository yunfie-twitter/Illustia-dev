# 作品を見る (イラスト・マンガ・小説)

画面下部のボトムナビゲーションバーおよび各ボタンから、様々なジャンルの作品へアクセスできます。

---

## ナビゲーションと画面構成

### 1. 下部ナビゲーションバー (5 つのメインタブ)
アプリ画面下部には、メインとなる 5 つのタブが配置されています。

| タブ | アイコン | 説明 |
| :--- | :--- | :--- |
| **ホーム** | `Home` | 「おすすめ」および「フォロー中」の 2 タブで最新投稿をチェックできます |
| **検索 / ショート** | `Search` / `ShortsFeed` | キーワード検索画面。ショートフィード有効時は縦スワイプ観賞フィードになります |
| **ブックマーク** | `Bookmarks` | 自身が保存した公開 / 非公開ブックマーク作品の一覧 |
| **ランキング** | `Ranking` | デイリー、ウィークリー、マンスリー、R-18 各種の人気作品一覧 |
| **その他** | `More` | 設定、閲覧履歴、ダウンロードキュー、オフラインライブラリ、通知へのハブ |

---

### 2. 小説画面の開き方 (`NovelScreen`)
小説作品（一覧・ランキング・連載・本文リーダー）は、**ホーム画面などの右上にある「小説アイコン（ボタン）」** をタップして呼び出します。

---

## 各メディア別ビューアの機能

### 1. イラスト・マンガビューア
- **拡大表示**: ピンチイン / ピンチアウト（二本指操作）またはダブルタップで画像を拡大・縮小。
- **マンガ表示モード**: 連続スライド表示、単ページ切り替え、見開き表示。
- **画質制御**: データ通信量に合わせてサムネイル解像度、詳細表示画質、原寸表示を個別に設定可能。

### 2. うごイラ (動くイラスト)
- 連続フレーム画像を自動解凍し、スムーズにアニメーション再生。
- 画面タップで再生 / 一時停止、コマ送り操作が可能。

### 3. 小説リーダー
- **縦書き表示**: 和文書籍に最適な「縦書き表示」と右開きページ推移をサポート。
- **背景と文字のカスタマイズ**: 文字サイズ、行間、背景色（ホワイト / セピア / ダーク）を変更可能。
- **挿絵**: 本文中の挿絵タグを自動検出してインライン表示およびタップ拡大表示。
