# 作品を見る (イラスト・マンガ・小説)

---

## 画面構成とナビゲーション

### 1. ホーム画面のタブ
ホーム画面のメイン領域では、タブをスライドして作品を切り替えられます。

- **おすすめ (Feed)**: あなたの好みに合わせたイラストやマンガを表示します。
- **フォロー中 (Following)**: フォローしている絵師さんの最新投稿をタイムラインでチェックできます。

### 2. 小説画面の開き方 (`NovelScreen`)
小説作品（一覧・シリーズ・本文リーダー）は、**ホーム画面右上にある「小説アイコン（ボタン）」** をタップすることで開きます。

### 3. その他の閲覧モード
- **ランキング**: 下部ナビゲーションまたはメニューから、今日の人気作品や各種ランキングを表示できます。
- **ショートフィード**: 設定から有効化すると、フルスクリーン縦スワイプで作品を次々観賞できます。

---

## ビューアの便利な機能

### 1. イラスト・マンガ
- **拡大表示**: 二本指で広げる（ピンチアウト）か、ダブルタップで画像を拡大できます。
- **マンガの見開き表示**: 設定から、ページ切り替え方法や見開き表示を選べます。

### 2. うごイラ (動くイラスト)
- 動画のように自動再生されます。画面をタップして一時停止やコマ送りができます。

### 3. 小説リーダー (`NovelScreen`)
- **縦書き表示**: 本物の文庫本のように「縦書き」で読むことができます。
- **文字サイズと背景色**: 読みやすい文字の大きさや、目にあ優しい背景色（セピアやダーク）に変更できます。
- **挿絵**: 文章の中にある絵をタップすると大きく表示されます。
