# 作品を見る (イラスト・マンガ・小説)

---

## 画面の切り替え

ホーム画面では、見たいジャンルに合わせてタブを切り替えられます。

- **おすすめ**: あなたの好みに合わせたイラストやマンガを表示します。
- **フォロー中**: フォローしている絵師さんの最新投稿をタイムラインでチェックできます。
- **ランキング**: 今日の人気作品や、週間・月間ランキング、R-18 ランキングなどを確認できます。
- **ショートフィード**: TikTok や Reels のように、縦スワイプで作品を次々見られます。
- **小説**: 小説の検索や連載シリーズ作品が探せます。

---

## ビューアの便利な機能

### 1. イラスト・マンガ
- **拡大表示**: 二本指で広げる（ピンチアウト）か、ダブルタップで画像を拡大できます。
- **マンガの見開き表示**: 設定から、ページ切り替え方法や見開き表示を選べます。

### 2. うごイラ (動くイラスト)
- 動画のように自動再生されます。画面をタップして一時停止やコマ送りができます。

### 3. 小説リーダー
- **縦書き表示**: 本物の文庫本のように「縦書き」で読むことができます。
- **文字サイズと背景色**: 読みやすい文字の大きさや、目にあ優しい背景色（セピアやダーク）に変更できます。
- **挿絵**: 文章の中にある絵をタップすると大きく表示されます。
