# 画像の保存と一括ダウンロード

---

## 画像を保存する

- **原寸画質で保存**: 画質を落とさず、オリジナルの綺麗な画像のままスマホに保存されます。
- **一括ダウンロード**: 複数ページのマンガも、1 タップで全ページをまとめて保存できます。

---

## 便利な自動設定

設定から、ダウンロード時の動作をカスタマイズできます。

- **作者別フォルダ分類**: 保存したときに「作者名」ごとにフォルダを分けて整理してくれます。
- **保存時に自動ブックマーク**: 画像を保存したのと同時に、Pixiv 上でも自動でブックマークに追加してくれます。

---

## 保存した作品を見る (オフラインライブラリ)

保存した画像は「ダウンロード一覧」からいつでも確認できます。インターネットが繋がっていない場所（オフライン）でも、保存済みの作品を自由に閲覧できます。
