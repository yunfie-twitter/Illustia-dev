# 端末間データ同期 (PallaSync)

PallaSync を使うと、スマホとタブレットなど複数の端末間で、アプリの設定やお気に入りタグ（ウォッチリスト）を自動的に同期・バックアップできます。

---

## 安全な仕組み

- **暗号化して送信**: 同期されるデータは、お使いの端末上で高度に暗号化されてから送信されます。
- **サーバーでも解読不可**: サーバー側には暗号化されたデータしか保存されないため、第三者にデータを見られる心配はありません。

---

## 使い方

1. 設定画面から「PallaSync」をオンにします。
2. 同期したい別の端末でも同じようにオンにすると、バックグラウンドで自動的に最新の状態に同期されます。
