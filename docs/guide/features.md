# 主な機能

## ホームと閲覧

ホームでは、おすすめ作品とフォロー中ユーザーの新着作品を切り替えて確認できます。

- イラスト、マンガ、小説の表示
- 複数ページ作品の閲覧
- 全画面画像ビューアー
- 関連作品と作者プロフィール
- デイリー、ウィークリー、マンスリーランキング

## 検索

作品、タグ、ユーザーを検索できます。タイトルやキャプション、完全一致などの条件を使い分け、ブックマーク数や並び順で結果を絞り込めます。

よく確認するタグはウォッチリストへ登録できます。最近見た作品と検索履歴から、途中だった探索へ戻ることもできます。

## ブックマークとフォロー

- 公開・非公開ブックマーク
- ユーザーのフォローと解除
- ダウンロード時の自動ブックマーク
- 条件に応じた自動ダウンロード

操作結果が反映されない場合は、通信状態を確認して画面を更新してください。

## ダウンロード

作品の単一ページ、または全ページを保存できます。設定から同時ダウンロード数を調整し、ダウンロードキューで進行状況を確認できます。

::: info 保存先へのアクセス
Androidのバージョンや選択した保存先によって、初回のみフォルダやメディアへのアクセス許可が表示される場合があります。
:::

## Androidとの連携

Palleriaは共有されたPixiv URLやテキストを受け取り、対応する作品や検索画面を開けます。ホーム画面ウィジェットやライブ壁紙など、Android向けの連携機能も含まれます。
