# ログイン

Palleriaでは、Webログインとリフレッシュトークンの2つの方法を利用できます。

## Webログイン

多くの方にはWebログインをおすすめします。アプリ内に表示されるPixivのログインページで認証します。

1. Palleriaを起動して「Webログイン」を選びます。
2. 表示されたPixivのページでログインします。
3. 認証が完了するとPalleriaに戻ります。

ログインページや二段階認証の表示はPixiv側の仕様により変わることがあります。

## リフレッシュトークン

すでに有効なPixivリフレッシュトークンを持っている場合は、トークンを入力して直接ログインできます。

::: danger トークンを共有しないでください
リフレッシュトークンはパスワードと同様に扱ってください。スクリーンショット、Issue、ログ、チャットなどに貼り付けないでください。トークンを知った第三者がアカウントへアクセスできる可能性があります。
:::

## ログインできないとき

- 端末の日時が自動設定になっているか確認する
- ネットワークを切り替えて再試行する
- VPN、広告ブロッカー、独自DNSを一時的に無効にする
- Palleriaを最新版に更新する
- Pixiv公式サイトでアカウントにログインできるか確認する

解決しない場合は、トークンや個人情報を含めずに[GitHub Issues](https://github.com/yunfie-twitter/Palleria/issues)へ状況を報告してください。
