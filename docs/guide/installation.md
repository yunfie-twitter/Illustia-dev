# インストール

## インストール方法

### 1. F-Droid リポジトリ経由 (推奨)

F-Droid または Droid-ify 等のクライアントに専用リポジトリを追加することで、アプリの自動更新に対応します。

リポジトリ URL:
```text
https://yunfi.f5.si/Palleria/repo/
```

リポジトリフィンガープリント:
```text
28A7F64F373AC1AD5FBB4822870E2E07B2B204C7EC71E58CE40F9D54EF2727D9
```

1. F-Droid の「設定」>「リポジトリの追加」を開きます。
2. 上記 URL を追加し、リポジトリの同期を行います。
3. パッケージ名 `com.yunfie.illustia`（Palleria）を検索してインストールします。

---

### 2. GitHub Releases 経由 (単体 APK)

[GitHub Releases](https://github.com/yunfie-twitter/Palleria/releases/latest) から直接 APK ファイルを入手して手動インストールします。

1. 最新リリースの `Assets` から `Illustia-v5.0.0-release.apk`（または最新バージョンの APK）をダウンロードします。
2. 端末でファイルを開き、セキュリティダイアログに従って「このソースからのアプリを許可」を有効にしてインストールを実行します。
