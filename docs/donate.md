# 寄付・開発支援

Palleria は、オープンソース（GPL-3.0-only）として無償で開発・公開されています。

プロジェクトの継続的な機能追加、バグ修正、テスト端末の用意、F-Droid リポジトリおよび同期サーバーの運用維持のため、皆様からのご支援・寄付を歓迎しています。

---

## 寄付方法

### Kyash による寄付 (推奨)

個人送金・決済アプリ **Kyash** を通じたご支援が可能です。

- **Kyash ID**: `@yunfie`

#### 寄付手順
1. スマートフォンで **Kyash** アプリを起動します。
2. 「送金」画面を開き、検索窓に ID `@yunfie` を入力します。
3. 送金額を入力し、任意で応援メッセージを添えて送金を実行してください。

---

## その他のサポート方法

金銭的な支援以外にも、以下の方法でプロジェクトに貢献していただけます。

- **GitHub Star の付与**: [Palleria リポジトリ](https://github.com/yunfie-twitter/Palleria) にスターをつけて応援する。
- **バグレポート・機能提案**: アプリの不具合や改善案を [GitHub Issues](https://github.com/yunfie-twitter/Palleria/issues) で共有する。
- **アプリの共有**: お困りの方や友人へ Palleria を紹介・シェアする。

温かいご支援とご協力に感謝いたします！
