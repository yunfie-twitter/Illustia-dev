ログインと認証 ​

Palleria では Pixiv API の利用にあたり OAuth2 認証を用います。アカウント情報は暗号化され端末内（Android KeyStore / Room DB）に保存されます。

ログイン方式 ​

1. Web ログイン (推奨) ​

アプリ内ブラウザ（Chrome Custom Tabs または WebView）で Pixiv の公式 OAuth ログインページを表示して認証します。

  1. ログイン画面で「Web ログイン」をタップします。
  2. Pixiv のログイン画面が表示されるので、ID/パスワードまたは各サードパーティ連携（Google / Apple / Twitter）でログインします。
  3. ログイン完了後、スキーム pixiv:// によるリダイレクトが発生し、取得された access_token および refresh_token が保存されます。

2. リフレッシュトークンログイン ​

すでに取得済みの refresh_token（文字列）を直接入力して認証を行う方法です。

  1. ログイン画面で「リフレッシュトークンでログイン」を選択します。
  2. refresh_token を入力し「ログイン」をタップすると、Rust API クライアント経由でトークンの有効性が検証されます。

WARNING

refresh_token はアカウント操作が可能な機密データです。外部への漏洩にご注意ください。

複数アカウント管理 ​

Palleria は複数アカウントの保持と切り替えに対応しています。

  • アカウント切り替えシート: アプリ内から保存済みアカウントの一覧を呼び出し、再ログインなしで即座にアクティブアカウントを変更できます。
  • データ管理: アカウントごとに AccountEntity テーブルで管理され、設定画面から個別のログアウトやトークン破棄が可能です。
